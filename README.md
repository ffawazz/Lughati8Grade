# لغتي – ثاني متوسط (الفصل الأول)

تطبيق لمراجعة مادة لغتي: قراءة بنطق الكلمة بالضغط، مفردات مع بطاقات بتكرار متباعد، نحو وإملاء وتعبير وشعر، جولات من ١٠ أسئلة، مراجعة الأخطاء، سلسلة أيام وهدف أسبوعي، ولوحة لولي الأمر. يعمل كموقع (GitHub Pages) وكتطبيق أندرويد (WebView).

## المحتوى
مصدره الكتاب (النسخة المحلولة على موقع كتبي، الوحدات ١–٣). كل عنصر يحمل `src`: «كتاب ص…» أي منقول من الكتاب، أو «مضاف» أي كتبه التطبيق، وتُعرض قائمة «المضاف» لولي الأمر للتحقق. تُضاف الدروس في `content/unitN.js`.

**الحالة:** الوحدة ١ مكتملة، والوحدة ٢ حتى إستراتيجية الكتابة (ص١٧٦)، ومن الوحدة ٣ درس الهمزة المتطرفة (الدرس الافتراضي الحالي). المتبقي: بقية الوحدتين ٢ و٣ — انظر `docs/PROGRESS.md`.

## البناء
- ويب: افتح `index.html` أو `python3 -m http.server`.
- أندرويد: `cd android && ./gradlew assembleDebug` (يتطلب SDK 34). الناتج: `android/app/build/outputs/apk/debug/app-debug.apk`، والنسخة المُعدّة في `dist/`.
- اختبار: `node test/run.js` (Playwright + Chromium). ملف `test/fixture.js` بيانات اختبار فقط ولا يُحزَّم.
