# لغتي – ثاني متوسط (الفصل الأول)

تطبيق ويب ثابت (بدون تثبيت أو خادم) لمراجعة مادة لغتي: توزيع ١٧ أسبوعًا و٥٦ درسًا، شروح القواعد والإملاء والكتابة، اختبارات قصيرة، تتبع التقدم، ووضع ليلي، ويعمل دون اتصال.

التشغيل: افتح `index.html` أو قدّم المجلد بأي خادم ثابت (`python3 -m http.server`).

المصدر: https://www.kottby.net/m2/fsl-eight/lgtyy-8/ — الهيكل والتوزيع منه، والمصادر الأخرى (الملخص، الأوراق، الاختبارات) مرتبطة بروابطها الأصلية ولم تُنسخ. الشروح والأسئلة مكتوبة للتطبيق؛ راجع الكتاب المدرسي للتأكد.
